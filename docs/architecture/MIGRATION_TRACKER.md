## Phase 1 notes

- **Lockfiles:** the three per-app lockfiles were replaced by one root `pnpm-lock.yaml`. Direct dependencies resolve to exactly the versions previously locked, enforced by the `overrides` block in `pnpm-workspace.yaml`. Remove an override only as a deliberate upgrade.
- **API runtime:** `pnpm --filter @crm/api build` then `node dist/server.js` (the start command changed from `node src/server.js`). Dev uses `tsx watch`. Docker images live in `infrastructure/docker/` and are built from the repo root.
- **Behaviour changes (intentional, minimal):**
  - `x-request-id` is on every response.
  - `x-powered-by` is removed.
  - Thrown or unhandled errors on legacy routes return JSON `{success:false,message,requestId}` instead of Express's HTML page, and stack traces are never returned.
  - `PUT /api/lead-messages/:id/status` now requires auth.
  - The gold rate API key is read from `GOLD_API_KEY`.
