# Launch checklist

Status of every launch item at the end of Phase 7. **PASS** = done and verified by automated checks in this repository. **BLOCKED** = must be completed before launch and is outside the code (operator/credential/provider action). **MANUAL ACTION** = operator configuration or verification that the code supports but cannot perform or prove on its own.

Production launch is allowed only when no item is BLOCKED and every MANUAL ACTION is recorded as done (name, date).

- Lead search trigram indexes and dashboard-summary caching when volume requires ([PERFORMANCE.md](PERFORMANCE.md)).
- In-place `WEBHOOK_SECRET_KEY` rotation (re-encryption job).
- Grafana dashboard JSON from the specification in [MONITORING.md](MONITORING.md#dashboard-specification).
